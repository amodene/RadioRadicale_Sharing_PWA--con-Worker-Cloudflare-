
# Web Hub & Radio Radicale PWA

Repository monorepo contenente:

1. **Landing Page:** Indice delle applicazioni disponibili.
2. **Radio Radicale PWA (`/radio-radicale/`):** Web App standalone per consultare e condividere il palinsesto con minutaggio esatto, dotata di Service Worker offline-ready.
3. **Altro Progetto (`/altro-progetto/`):** Applicazione indipendente.
4. **Cloudflare Worker (`/Cloudflare-Worker/`):** Codice sorgente dell'Edge API serverless per lo scraping e il bypass CORS.

Distribuito pubblicamente tramite **GitHub Pages**.
